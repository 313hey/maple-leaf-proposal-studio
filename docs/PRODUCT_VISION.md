# Maple Leaf Proposal Studio — Product Vision

Help a small education travel team turn trusted, reusable content into accurate, client-ready study tour proposals with minimal repeated entry. Staff should be able to understand the workflow without training or technical help.

The long-term target is to upload a customer brief, cost calculation sheet, and itinerary, then receive a professional, visually polished, editable proposal for human review and export. This is a product direction, not a claim that the current Studio already accepts all three inputs or generates a finished draft automatically.

The editor should remain fast and predictable for long itineraries. Project work, attraction records, and class templates must stay recoverable when a browser, network, or cloud service fails. Shared data needs visible sync status and conflict handling; an export must never imply it contains cloud-only records when it does not.

Structured content and a reliable document pipeline can support assisted drafting. Any AI integration is a separate decision and must preserve human review, source attribution, privacy, and cost control.
