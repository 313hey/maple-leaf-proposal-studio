# Product Roadmap

## Current priorities

1. **Data recovery clarity:** allow an explicitly local project backup when cloud reads fail. Keep the existing complete cloud plus local backup as the normal path.
2. **Sync confidence:** make pending, failed, and conflicting project edits easy to identify and recover without hiding the local copy.
3. **Long proposal responsiveness:** profile editing, day switching, and export using representative 21-day projects before changing the save pipeline.

## Later candidates

- Faster first use on a new device with lightweight project metadata, subject to a backward-compatible schema plan.
- Structured, reusable proposal content with clear provenance.
- Assisted drafting only after the source, review, privacy, and cost model is agreed.

Do not migrate or delete production data as part of roadmap exploration. Reprioritize from measured user impact and observed failures.
